# confed-cloud

The Confluence Cloud client of [confed](https://github.com/hxmn/confed): pages, labels,
attachments, page and inline comments over REST v2, with REST v1 where v2 has no
equivalent (CQL search, users, groups), space creation, and space permissions or space
roles, whichever the site uses.

This crate is developed for confed and its API follows confed's needs; it is published
so `confed` can be installed from crates.io. Licensed under MIT or Apache-2.0.
