# confed-tui

The interactive terminal views of [confed](https://github.com/hxmn/confed),
`confed tui`: browse the space, preview and diff pages, resolve conflicts in a
three-pane view, and sync — through the same engine calls as the commands.

This crate is developed for confed and its API follows confed's needs; it is published
so `confed` can be installed from crates.io. Licensed under MIT or Apache-2.0.
