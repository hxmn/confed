# confed-cli

The commands of [confed](https://github.com/hxmn/confed), the offline-first Confluence
editor — `clone`, `fetch`, `pull`, `push`, `status`, `diff`, `comment` and the rest —
with their human and JSON output and exit codes. The `confed` binary runs it.

This crate is developed for confed and its API follows confed's needs; it is published
so `confed` can be installed from crates.io. Licensed under MIT or Apache-2.0.
